= VCL-ut Verification Stance (proof-backed)
:toc:
:sectnums:


WARNING: vcl-ut is the interface between *hypatia* and *verisim*; both sides
trust safety claims made here. This document states *precisely* what is and is
not machine-verified, and takes precedence over any "verified" / "type-safe" /
"formally proven" phrasing in `README.adoc`, `PROOF-NEEDS.md`, or module
doc-comments. It is the proof-backed companion to (and supersedes) the
doc-only `docs/VERIFICATION-STANCE.adoc` (PR #19).

Tracked under hyperpolymath/standards#124.

== Headline finding (Phase 0 audit) — and Phase 1 + 2 status

*Phase 0 audit (origin/main, reproduced with idris2 0.8.0):* the shipped
Idris2 "proof corpus" *did not compile at all*, at every layer, and had
*never been machine-checked* (no `.ipkg`/Makefile/CI for `src/core/**` —
only the unrelated trivial `src/abi/vclut.ipkg`, itself absent from CI).
The previously-circulated stance ("the dependent-type apparatus exists but
is not connected") was *too generous*: the apparatus did not even
typecheck. The concrete blockers were:

* `src/interface/abi/Types.idr` — missing `import Decidable.Equality`;
  `DecEq SafetyLevel/VclTotalError/QueryMode` malformed
  (`decEq _ _ = No absurd`, no `Uninhabited`); `CPtr p _ = Bits (ptrSize
  p)` ill-typed; `createQueryHandle` omitted the `So (ptr /= 0)` witness;
  `thisPlatform` used `%runElab` without `%language ElabReflection`.
* `src/core/Grammar.idr` — `Expr`/`Statement`/`EpistemicClause`/
  `EpistemicRequirement` mutually forward-referenced with no `mutual`
  block.
* Latent (never compiled): `Schema` (name-shadowing in `lookupField`),
  `Levels` (helper predicates declared after the level data they index),
  `Checker` (mis-scoped `where` for `agentEq`, `CheckResult` ambiguity,
  `let`-tuple parse, and a non-structural `extractFieldRefs ⇄
  statementFieldRefs` recursion across `ESubquery Statement`),
  `Composition` (forward refs, deleted `AllParameterised` still
  referenced, wrong `CertL6+` arities, non-reducing `rewrite`s).

*Phase 1–4 status (RESOLVED); Phase 5 boundary reinforcement — BOTH
tiers RESOLVED:* every blocker above is fixed *honestly* and the
corpus compiles (**12 modules**: Phase 4 = `LayoutProofs` + L6–L10
`composeJoin` closure, PR #24; Phase 5 / vcl-ut#25 added
`Interface.{WireDecode,WireConformance}` — the certified wire/schema
decoder + cross-language `Refl` conformance, the faithful Rust
decision port, the recompute-`wasm32` artefact (**Tier-1

**Phase 2** de-vacuized L2/L3/L5
(new shared decider module `VclTotal.Core.Decide`, evidence-carrying

== What IS genuinely machine-verified by this PR

`verification/proofs/SafetyL4Model.idr` — checked by **idris2 0.8.0,
`idris2 --check`, exit 0, with `%default total` and ZERO
`believe_me`/`really_believe_me`/`postulate`/`assert_total`/`idris_crash`/
`sorry`**. It reproduces the *exact mathematical content* of the in-repo
Level-4 (SQL-injection) remediation against a minimal, self-contained,
byte-faithful model of the relevant AST fragment, proving:

. `NoRawUserInput` is no longer *vacuous*. It previously had the single
  catch-all constructor `AllParameterised : NoRawUserInput stmt`, inhabiting
  it for *every* statement — including a WHERE clause that is pure string
  interpolation. It now carries real evidence: `whereHasStringLit w = False`.
. `checkLevel4Sound` — *soundness of the decision procedure*: if
  `checkLevel4` accepts, the statement genuinely carries the (now real)
  `NoRawUserInput` witness. This is the certificate↔checker connection for
  L4; it was previously unstateable (predicate vacuous, checker returned a
  bare `Bool`).
. `injectionRejected` — negative test: a WHERE bearing a string literal
  (`… = '1=1'`) is *rejected*. Under the old vacuous predicate the
  corresponding query "type-checked" at Level 4.
. `noRawUserInputCompose` — Level-4 injection-freedom is *genuinely* closed
  under join composition, because `joinWhere` introduces no string literal
  not already present. This replaces the two
  `MkL4 _ AllParameterised` uses in `Composition.compositionPreservation`,
  whose "preservation theorem" was therefore *vacuously true*.

As of Phase 1 the in-repo source fix is no longer model-only: it is
machine-checked *in situ*. `Checker.checkLevel4Sound`
(`checkLevel4 stmt = (True, m) -> L4_InjectionProof stmt`, proved with
`with (whereHasStringLit stmt) proof p`, no escape) and
`Composition.noRawUserInputCompose` typecheck inside the compiling corpus
and are *identical in content* to the `SafetyL4Model.idr` lemmas of the
same names (model: `MkNoRawUserInput : whereHasStringLit w = False ->
NoRawUserInput w`; in-repo: `L4_InjectionProof = MkL4 stmt (NoRawUserInput
stmt)` with the same `whereHasStringLit stmt = False` evidence). L4
injection-freedom is therefore now genuine *and* wired through the
type-checked corpus — though still not through the (stubbed) FFI.

*Phase 2* extends the same architecture to L2/L3/L5 *in the corpus*
(there is no separate model file for these — they are verified in situ
by the CI `--build`): predicates carry a `= True` equality on the
shared `VclTotal.Core.Decide` deciders; `Checker.checkLevel2/3/5` are
defined through those deciders; `checkLevel2Sound`/`checkLevel3Sound`/
`checkLevel5Sound` prove acceptance ⇒ predicate (same `with … proof p`,
no escape, as L4); and `Composition`'s `l2Compose`/`l3Compose`/
`l5Compose` are genuine (L3 via guard-set monotonicity). The remaining
honest gaps (uncertified `checkQuery`; L1/L6–L10 soundness; L3 subquery/
heuristic scoping; unsound excluded `ABI.Layout/.Foreign`) are in the
OWED section.

== S2 (consonance transitions) — scope, certification ceiling, and OWED

*Surface.* S1 added the `Verb` discriminant
(`VSelect/VInspect/VVerify/VAssert/VDeclare/VRetract`) as an *additive*
`Statement` field: every L0..L10 predicate accesses `Statement` by named
field and ignores `verb`, so the addition reopened ZERO existing proofs
(the corpus is byte-identical except the one tag-only `Grammar.Verb`
extension). S2 adds the three remaining verbs — `MERGE`, `SPLIT`,
`NORMALISE` — but these are multi-subject / result-less and do NOT fit
`record Statement` (single `source`, always result-returning). They are
therefore a SEPARATE type `VclTotal.Core.Transition.Transition`, and the
top-level operation is the sum `VclOp = Query Statement | Transit
Transition`. Consequence: the entire L0..L10 statement corpus is
*untouched* by S2 — no statement proof is weakened, re-opened, or made
vacuous.

*What S2 certifies (HONEST, PARTIAL).* `Transition.idr` certifies, by the
same reflection-style `= True` discipline as L4..L10, a three-clause
admissibility decider `transitionAdmissible t schema`:

. *structural identity-distinctness* (`subjectsDistinct`) — `MERGE`'s two
  inputs differ; `SPLIT`'s two outputs differ; `NORMALISE` is
  single-subject (trivially distinct). This is proved NON-vacuous:
  `certifiedSubjectsDistinct : TransitionSafe t schema -> subjectsDistinct
  t = True` extracts the distinctness conjunct from the certificate (so a
  self-merge cannot carry a certificate).
. *evidence injection-safety* (`evidenceInjectionSafe`, L4 polarity) — the
  optional evidence `Expr` embeds NO raw string literal; `Nothing`
  evidence is safe. Reuses the single-source-of-truth `Grammar.hasStringLit`.
. *evidence type-compatibility* (`evidenceTypeCompat`) — reuses
  `Decide.whereComparisonsCompatible` on the evidence `Expr`; `Nothing` is
  vacuously compatible.

The achieved level is the `InjectionProof` rung (4) when admissible, else
−1 (`certifiedTransitionLevel`). There is NO L5+ ladder for a transition:
result-less `NORMALISE` *genuinely OMITS* `L5 ResultTyped` / `L6
CardinalitySafe` (it has no result set) — they are ABSENT, not vacuously
passed. An unjustified `NORMALISE` is *unrepresentable* (the
`RepairJustification` is a by-construction field), and the parser
fail-closes on a missing justification clause.

*Conservatism (no over-claim).* The S2 path only ever *narrows* what is
admitted: a transition that fails any clause certifies to −1, and a
syntactically-incomplete transition (e.g. unjustified `NORMALISE`) is
rejected at parse. A `Transit` is certified by `certified_transition_level`
ONLY — the trusted gate (`bin/vclt-gate.rs`) routes
`VclOp::Transit ⇒ run_transition`, NEVER down-casting a transition to the
`Statement` `certified_level`. The Rust type system makes the down-cast
unrepresentable (`certified_level` takes `&Statement`, not `&Transition`).

*Cross-language machine-pin (the doubly-trusted seam).* The transition
wire + verdict are pinned exactly as the statement path is:

* `to_wire_op` (Rust) ⇄ `fromWireOp` (certified Idris) on a distinct
  `VCLT` magic (a `VCLW`/`VCLS`/`VCLT` mix-up is a hard `BadMagic`). The
  Idris decoder is `%default total`, fuel-bounded, ZERO proof-escape, and
  reduces by `Refl` at compile time on the EXACT bytes the Rust encoder
  emits: `WireConformance.conformOpQ1` (a `Query`-wrapped statement),
  `conformT1` (`MERGE`), `conformT2` (`NORMALISE`). Oracle:
  `tests/conformance_emit.rs` `goldenOpQ1/goldenT1/goldenT2`.
* `certified_transition_level` (Rust port) ⇄ `certifiedTransitionLevel`
  (corpus): `ctlVerdict1/ctlVerdict2` `Refl`-reduce the corpus verdict to
  `4` on the same evidence-free fixtures the Rust oracle emits (`ctl1 =
  ctl2 = 4`). The Rust decider is a line-by-line port of the corpus
  deciders; the conformance is *same decider fact ⇒ same Rust verdict*.
* `tests/wire.rs` adds the SPARK-grade totality witnesses for the new
  codec (`op_roundtrip`, `op_decoder_total_on_garbage`,
  `op_decoder_total_with_valid_header`).

*DISCLOSED-OWED (recorded, fail-closed, NEVER faked).* The S2 certificate
is a floor, not a ceiling. It does NOT establish:

. *provenance-descent* — that a merged identity correctly inherits the
  provenance of BOTH inputs (only structural distinctness is checked, not
  identity conservation in the provenance graph).
. *engine-liveness* — that the `MERGE` inputs / `SPLIT` source actually
  exist and are live in the store (the gate is a pure function of
  (operation, schema); existence is the engine's obligation).
. *modality-presence for `NORMALISE`* — that the chosen
  `RepairJustification` modality is actually present/authoritative for the
  subject.
. *identity-vs-location* — `SubjectRef` is an identity handle checked only
  by *handle equality*; it is deliberately distinct from `Source` (a
  read-location) but is not yet cross-checked against the provenance graph.

*Boundary (this slice).* The Tier-2 recompute (`recompute-wasm`) and
attestation (`attest`) pipelines remain STATEMENT-only: they consume the
`VCLW` stream and `certified_level`. Extending the recompute/attestation
TCB to the `VCLT` transition stream is a separate, disclosed unit of work
(it requires a transition attestation format), not silently folded in
here.

  `wasm32`, Tier-2 C-ABI signed-attestation fallback.*
+
  ** *Tier-1 — recompute-PCC over `wasm32` (RESOLVED, the achieved
     tier).* The consumer is shipped the `wasm32` module
     (`src/interface/recompute-wasm`, `vcl_recompute`) + the wire
     bytes of a `(Statement, OctadSchema)` + the producer's claimed
     level, and **re-runs the certified decision itself**, comparing
     its verdict to the claim. This is proof-carrying code by
     *recomputation*, not by transporting a proof object: the consumer
     does not trust a proof term's provenance — it independently
     re-establishes the verdict. The TCB is (a) the once-proved corpus
     soundness `checkLevelNSound` (machine-checked in the CI-gated
     Idris corpus, *offline*-re-checkable with idris2, never in the
     runtime path), (b) the conformance pin that
     `vcltotal_parse::certified_level` is a faithful image of that
     corpus decision (`tests/conformance_emit.rs` ⇄
     `VclTotal.Interface.WireConformance`, `Refl`), and (c) the wasm
     runtime — *not* the whole certifier. Fail-closed: any malformed
     input or unmet level → Reject, never a fabricated level.
+
     *Why plain `wasm32` is sufficient (not a weaker choice).* Nothing
     structured crosses this boundary that would need
     type-preservation: opaque wire bytes in, an `i64` out, and the
     decoder+decider run *inside* the module. The wasm *type system*
     is therefore **not load-bearing** here — the guarantee is
     (a)+(b)+(c) above. AffineScript dependent/affine typing was
     load-bearing only for a *proof-term-transport* design, which was
     **rejected** (Idris2 ships no embeddable verified core kernel;
     building one is its own subproject). `affinescriptiser` is *not*
     used (disclosed, not an oversight — `src/interface/recompute-wasm/
     AFFINESCRIPTISER-NA.adoc`): it structurally requires ≥1
     `[[resources]]` and the entry is a pure resource-free verdict
     function (fabricating a resource to satisfy the tool would be the
     cargo-culting this doctrine forbids), and its own wasm backend is
     Phase-2-pending. The wasm verdict equals the conformance-pinned
     native verdict *by construction* (deterministic `cargo build` of
     the same pinned, pure, total source).
  ** *Tier-2 — C-ABI trusted-certifier attestation (FALLBACK, P5d —
     RESOLVED).* A C ABI erases types to machine words, so it cannot
     transport a re-checkable dependent `SafetyCertificate`; over a C
     ABI the honest ceiling is *trusted-certifier attestation*, and
     that ceiling is now reached. `src/interface/attest`
     (`vcltotal-attest`) mints an Ed25519 signature over
     `DOMAIN ‖ sha256(stmt_wire) ‖ sha256(schema_wire) ‖ level`, where
     `level` is the conformance-pinned `vcltotal_parse::certified_level`
     (the same faithful image of the corpus decision Tier-1 uses) and
     is signed **iff** `0..=10` — fail-closed, never a token for an
     unestablished level. The consumer Ed25519-verifies against the
     certifier's public key: the token is *unforgeable* and *bound*
     (a tampered query/schema/level/sig or wrong key all reject —
     machine-tested: roundtrip + 5 tamper variants + fail-closed +
     C-ABI). The previously-OWED `vclut_rs_verify` backend is this
     crate, linked into the `ffi/zig` shim (`vclut_verify_wire`) by
     `build.zig`; `zig build test` exercises the fail-closed path
     end-to-end across the Zig↔Rust boundary. Trust model, stated:
     the consumer trusts (a) the certifier's key is genuinely held and
     (b) the certifier ran the pinned decider before signing —
     strictly weaker than Tier-1 (which trusts neither; it
     recomputes). Real key provisioning is deployment (estate token
     vault). Spec: `src/interface/attest/ATTESTATION-FORMAT.adoc`;
     crypto (`ed25519-dalek`/`sha2`) is contained to this Tier-2 crate
     and never touches the zero-dep forbid-unsafe core.
+
  So "a re-checkable proof is impossible by construction" is true
  *only of the C-ABI fallback tier*, **not of any FFI**: Tier-1
  (recompute over `wasm32`) achieves consumer-side re-validation
  without transporting a proof at all. Recompute is, in one respect,
  *stronger* than proof-object PCC (no need to trust a transported
  term's provenance); its cost is recomputation, which for a static
  AST decision is negligible.
+

== Consumer guidance (hypatia / verisim)

* Treat *every* vcl-ut safety-level tag as an *advisory claim*, not a proof
  carrier. Do not weaken your own checks on the strength of a vcl-ut level.
* As of Phase 3, *all ten levels* (L1–L10) have a genuine
  machine-checked basis in the compiling, CI-gated corpus: non-vacuous
  predicates, deciders the checker is defined through, `checkLevelNSound`
  lemmas, and (L1–L10) closure under `composeJoin`; and
  `Checker.certifyAt`/`certifyRequested` assemble a genuine dependent
  `SafetyCertificate`. **However** this certificate is *not transported
  across the FFI* (the Zig/Rust side is a stub; the level tag a
  hypatia/verisim caller receives is an asserted integer, not the proof
  token). Cite vcl-ut at most as "machine-checked L1–L10 safety
  predicates + per-level checker soundness + a dependent
  `SafetyCertificate`, for the in-repo AST model, *not transported
  across the FFI*", noting the disclosed L3 subquery/heuristic scoping
  and the L6–L10 predicate shallowness above. Do not weaken your own
  checks on the strength of a vcl-ut FFI level tag.
* `VclTotal.ABI.Layout` is now *sound + CI-gated* (unsound claims
  deleted, not faked); its genuine alignment/no-padding theorems are
  OWED. `VclTotal.Legacy.Foreign` (formerly `VclTotal.ABI.Foreign`,
  retired 2026-06-02) contains *no proofs* (FFI plumbing) and its
  returned level tag is a Zig-side trusted assertion, NOT a verified
  claim — *do not use the legacy bindings*. The honest Idris-side
  path is **`VclTotal.ABI.Tier2`**, which returns a Tier-2
  Ed25519-signed attestation: still trust-the-certifier (the C-ABI
  ceiling), but cryptographically bound and tamper-evident, with the
  Rust crate's test suite enforcing the fail-closed contract. For
  the strongest guarantee, use Tier-1 recompute-PCC over `wasm32`
  (`src/interface/recompute-wasm`).
* *Transport (DELIVERED — Tier-1 recompute-PCC, P5c, vcl-ut#25).* The
  guarantee is **not** "trust our attestation". You are shipped the
  `wasm32` module `src/interface/recompute-wasm` (`vcl_recompute`) +
  the `(Statement, OctadSchema)` wire bytes + the claimed level. **Run
  it and compare**: a match means *you* have independently
  re-established the corpus-proved verdict — your TCB is the
