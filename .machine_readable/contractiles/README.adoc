= Operational Contractile Set
:toc:
:sectnums:

This is the repository's working set of per-verb A2ML policy files and Nickel
runner/schema definitions. It also provides examples for the templates under
`docs/templates/contractiles/`.

It is separate from the root `contractiles/` input used to generate
`contractile.just`, and from the legacy `.machine_readable/*.contractile`
format. The four locations have different consumers; see
`.machine_readable/README.adoc` for the authority map.

== Contents

* `must/`, `trust/`, `intend/`, `adjust/`, `bust/`, `dust/` — paired A2ML
  policy files and Nickel runners.
* `_base.ncl` — shared Nickel schemas and defaults.
* `INDEX.a2ml` — registry describing the contractile set.

== Maintenance

1. Change the relevant operational A2ML/Nickel pair together.
2. Run the repository's A2ML and Nickel/K9 validation before relying on an
   edited contract.
3. Update `INDEX.a2ml` when the registry or verb set changes.
4. Update `docs/templates/contractiles/` only when the contributor-facing
   starter templates themselves change; they are not copied wholesale over
   this working policy set.
